## GitHub Pages
1. Repository pubblico: `cora-client-manager-site`.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. In Custom domain inserire `coraclientmanager.dpdns.org`.
4. In DigitalPlat DNS creare il record richiesto da GitHub Pages.
5. Attendere propagazione, poi abilitare `Enforce HTTPS`.
